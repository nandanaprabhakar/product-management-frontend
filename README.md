# Product Management Frontend

## About the Project
This project is a Product Management Application developed using React.

## Technologies Used
- React
- Vite
- JavaScript
- Material UI (MUI)
- Bootstrap
- Axios
- React Router DOM

## Features
- User Signup and Login
- Display Products
- Add and Edit Products
- Category and Sub-category Management
- Product Variants
- Wishlist Management
- Search Products by Name
- Filter Products by Sub-category
- Pagination
